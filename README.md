# 🛒 Lista de Mercado Inteligente

Uma aplicação web moderna para gerenciamento de compras de mercado, desenvolvida em **React** com foco em **UI/UX**, **Acessibilidade (A11y)** e **Responsividade**.

## ✨ Funcionalidades

- 📝 **Adição e Validação de Itens:** Bloqueio de duplicados (case-insensitive) e limite dinâmico de 25 caracteres.
- ⏱️ **Métricas em Tempo Real:** Contador dinâmico de itens totais e pendentes.
- 🗂️ **Ordenação Automática:** Itens concluídos são movidos para o final da lista automaticamente.
- 💾 **Persistência de Dados:** Armazenamento local com `localStorage`.
- 📱 **Design Mobile-First:** Interface 100% responsiva para smartphones e desktops.
- ♿ **Acessibilidade:** Suporte a navegação por teclado e leitor de tela (propriedades ARIA).

## 🚀 Tecnologias Utilizadas

- **React.js** (Hooks: `useState`, `useEffect`)
- **JavaScript (ES6+)**
- **CSS3 / Flexbox / CSS Grid**
- **HTML5 Semântico**
